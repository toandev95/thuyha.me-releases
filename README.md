# thuyha.me releases

Release artifacts and update metadata for the thuyha.me desktop app.

## Install on macOS

Install or update thuyha.me from Terminal:

```bash
wget -qO- https://raw.githubusercontent.com/toandev95/thuyha.me-releases/main/install-macos.sh | bash
```

`wget` is not included with macOS by default. Use `curl` instead when needed:

```bash
curl -fsSL https://raw.githubusercontent.com/toandev95/thuyha.me-releases/main/install-macos.sh | bash
```
